# 🎵 Spotify Analytics

This is a simple Data Analysis mini project for analyzing Spotify music data and finding useful insights about songs, artists, albums, and audio features.

📌 Features

- Track Name
- Artist Name
- Album Name
- Genre
- Popularity
- Duration
- Danceability
- Energy
- Loudness
- Acousticness
- Speechiness
- Instrumentalness
- Liveness
- Valence
- Tempo

🎯 Target / Analysis

The project analyzes:

- Total Songs
- Average Song Popularity
- Most Popular Songs
- Most Popular Artists
- Most Popular Albums
- Average Song Duration
- Danceability Analysis
- Energy Analysis
- Acousticness Analysis
- Genre-wise Song Analysis
- Top Artists
- Popularity Trends

🔧 Algorithm / Technology

Python Data Analysis

Libraries used:

- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Streamlit
- Spotipy

- app.py
- spotify.csv

- README.md
